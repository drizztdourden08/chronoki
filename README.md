# ChronoKi

A desktop PC port of *Chrono Trigger* (SNES, 1995), built the way
*Relic of the Past* (RotP) ports *A Link to the Past*: a Brock app, drawn with
Tessera, the game's own code in its own packages.

**Ki** (機 / き, "kee") is the occasion or impetus that makes something happen, the right moment:
the figurative sense of "trigger".

## You bring the game

ChronoKi contains no game data. No ROM, graphics, music, text or other copyrighted asset of
*Chrono Trigger* is in this repository or in any build of it. To play, you supply your own
legally obtained copy of the original SNES ROM; ChronoKi reads what it needs from that file on
your machine.

ChronoKi is an unofficial fan project. It is not affiliated with or endorsed by Square Enix.
*Chrono Trigger* is a trademark of Square Enix.
